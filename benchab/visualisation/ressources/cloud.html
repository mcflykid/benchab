Configurer mon compte une première fois

Dans le terminal de ce Mac, depuis BENCHAB 3D :

uv run benchab machine session-compte -- --configurer

L’e-mail puis le mot de passe sont saisis dans le terminal, le mot de passe sans écho. Ils restent dans un fichier privé sur ce Mac. Ne les saisir ni dans cette page ni dans un chat. Les renouvellements sont ensuite gérés lors des lectures.
