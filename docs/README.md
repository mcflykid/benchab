Le [corpus technique](../benchab/reference/connaissances.jsonl) conserve les faits
avec leur portée, leurs conditions, leur preuve et les occurrences établies ou
inconnues. Les identifiants de [sources anonymisées](../benchab/reference/sources-savoir.jsonl)
permettent de vérifier la provenance sans publier les noms des projets.
Après initialisation, chercher un sujet avec
`benchab connaissances memoire chercher "surplomb"` ; les traces historiques ne
remplacent pas les commandes et corrections actuelles de ces guides.
