# Signalement de sécurité

Ne publiez pas de jeton, secret, donnée privée, détail exploitable ou reproduction
complète dans une issue, une discussion ou une pull request publique.

Utilisez le signalement privé de vulnérabilité proposé par GitHub pour ce dépôt,
s’il est disponible. Sinon, contactez un mainteneur en privé via GitHub afin
d’obtenir un canal adapté avant de transmettre les détails. Attendez-vous à
échanger la portée affectée, les versions concernées, les conditions nécessaires
et une reproduction minimale expurgée. N’incluez aucun secret réel dans le
signalement ; révoquez-le immédiatement s’il a été exposé.

Le scanner de frontière exécuté en CI signale les chemins et catégories
concernés, sans restituer les valeurs détectées. Ce contrôle automatique ne
remplace pas un signalement privé ni une revue de sécurité.
